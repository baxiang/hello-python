## 第二部分 - 实现步骤

### 2.1 sys.argv 基础

#### 概念说明

`sys.argv` 是一个列表，包含运行脚本时传入的所有参数。

```
┌─────────────────────────────────────────────────────────────┐
│                  sys.argv 结构                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  命令行：python tool.py prefix /tmp new_                     │
│                                                             │
│  sys.argv = ["tool.py", "prefix", "/tmp", "new_"]           │
│               ↑           ↑         ↑       ↑              │
│              [0]          [1]       [2]     [3]             │
│           脚本名称       子命令    目录    前缀参数            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 示例代码

```python
# argv_demo.py
import sys


def main() -> None:
    print(f"参数数量：{len(sys.argv)}")
    for i, arg in enumerate(sys.argv):
        print(f"  sys.argv[{i}] = {arg!r}")


if __name__ == "__main__":
    main()
```

运行 `python argv_demo.py hello world 123` 输出：

```
参数数量：4
  sys.argv[0] = 'argv_demo.py'
  sys.argv[1] = 'hello'
  sys.argv[2] = 'world'
  sys.argv[3] = '123'
```

### 2.2 参数验证

#### 概念说明

命令行工具需要对参数做基本验证：参数数量是否正确、目录是否存在、命令是否合法。

#### 示例代码

```python
# arg_validate.py
import sys
from pathlib import Path


COMMANDS = {"prefix", "suffix", "timestamp", "organize", "duplicates"}


def validate_args() -> tuple[str, str, list[str]]:
    """验证并解析命令行参数

    Returns:
        (command, directory, extra_args) 三元组
    """
    if len(sys.argv) < 3:
        print("用法: file-processor <命令> <目录> [参数]")
        print(f"可用命令: {', '.join(sorted(COMMANDS))}")
        sys.exit(1)

    command = sys.argv[1]
    directory = sys.argv[2]
    extra_args = sys.argv[3:]

    if command not in COMMANDS:
        print(f"错误：未知命令 '{command}'")
        print(f"可用命令: {', '.join(sorted(COMMANDS))}")
        sys.exit(1)

    if not Path(directory).is_dir():
        print(f"错误：目录不存在 '{directory}'")
        sys.exit(1)

    return command, directory, extra_args
```

### 2.3 子命令分发

#### 概念说明

用字典将命令名映射到处理函数，代替冗长的 `if/elif` 链。

```
┌─────────────────────────────────────────────────────────────┐
│              两种分发方式对比                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  方式 1：if/elif 链（不推荐）                                 │
│  if command == "prefix":                                    │
│      handle_prefix(...)                                     │
│  elif command == "suffix":                                  │
│      handle_suffix(...)                                     │
│  elif command == "timestamp":    ← 每加一个命令要改三处       │
│      ...                                                    │
│                                                             │
│  方式 2：字典分发（推荐）                                     │
│  handlers = {                                               │
│      "prefix": handle_prefix,                               │
│      "suffix": handle_suffix,   ← 只需在字典里加一行         │
│      "timestamp": handle_timestamp,                         │
│  }                                                          │
│  handlers[command](directory, extra_args)                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 示例代码

```python
# dispatcher.py
from processor.operations import FileOperations


def handle_prefix(directory: str, args: list[str]) -> None:
    prefix = args[0] if args else "new_"
    results = FileOperations.add_prefix(directory, prefix)
    for r in results:
        print(r)
    print(f"\n完成：共重命名 {len(results)} 个文件")


def handle_suffix(directory: str, args: list[str]) -> None:
    suffix = args[0] if args else "_processed"
    results = FileOperations.add_suffix(directory, suffix)
    for r in results:
        print(r)
    print(f"\n完成：共重命名 {len(results)} 个文件")


def handle_timestamp(directory: str, args: list[str]) -> None:
    results = FileOperations.add_timestamp(directory)
    for r in results:
        print(r)
    print(f"\n完成：共重命名 {len(results)} 个文件")


def handle_organize(directory: str, args: list[str]) -> None:
    mode = args[0] if args else "extension"
    if mode == "extension":
        result = FileOperations.organize_by_extension(directory)
    else:
        result = FileOperations.organize_by_date(directory)
    for category, count in sorted(result.items()):
        print(f"  {category}: {count} 个文件")
    print(f"\n完成：共整理 {sum(result.values())} 个文件")


def handle_duplicates(directory: str, args: list[str]) -> None:
    result = FileOperations.find_duplicates(directory)
    if not result:
        print("未发现重复文件")
        return
    total = sum(len(files) for files in result.values())
    for size, files in sorted(result.items(), reverse=True):
        print(f"\n大小 {size:,} 字节（{len(files)} 个文件）：")
        for f in files:
            print(f"  {f}")
    print(f"\n发现 {len(result)} 组重复，共 {total} 个文件")


# 命令 → 处理函数的映射
HANDLERS = {
    "prefix": handle_prefix,
    "suffix": handle_suffix,
    "timestamp": handle_timestamp,
    "organize": handle_organize,
    "duplicates": handle_duplicates,
}
```

**关键代码说明：**

| 代码 | 含义 | 为什么这样写 |
|------|------|-------------|
| `HANDLERS = {"prefix": handle_prefix, ...}` | 命令到函数的字典映射 | 新增命令只改字典，不改分发逻辑 |
| `args[0] if args else "new_"` | 有参数用第一个，否则用默认值 | 使可选参数有合理默认值，减少用户必填项 |
| `sorted(result.items(), reverse=True)` | 按文件大小从大到小排序 | 大文件排在前面，用户优先关注占空间多的重复文件 |

### 2.4 完整 CLI 入口

以下是本项目 `processor/cli.py` 的完整实现：

```python
# processor/cli.py
import sys
from pathlib import Path
from processor.operations import FileOperations


COMMANDS = {"prefix", "suffix", "timestamp", "organize", "duplicates"}

HELP_TEXT = """
文件批量处理工具

用法：
  file-processor <命令> <目录> [参数]

命令：
  prefix     <目录> [前缀]      添加文件名前缀（默认 "new_"）
  suffix     <目录> [后缀]      添加文件名后缀（默认 "_processed"）
  timestamp  <目录>             为文件名添加当前时间戳
  organize   <目录> [模式]      整理文件（模式：extension 或 date，默认 extension）
  duplicates <目录>             查找可能重复的文件

示例：
  file-processor prefix /tmp/photos vacation_
  file-processor organize /tmp/downloads extension
  file-processor duplicates /tmp/backup
"""


def main() -> None:
    if len(sys.argv) < 2 or sys.argv[1] in ("-h", "--help"):
        print(HELP_TEXT)
        return

    if len(sys.argv) < 3:
        print("错误：请提供命令和目录")
        print("运行 file-processor --help 查看帮助")
        sys.exit(1)

    command = sys.argv[1]
    directory = sys.argv[2]
    extra_args = sys.argv[3:]

    if command not in COMMANDS:
        print(f"错误：未知命令 '{command}'")
        sys.exit(1)

    if not Path(directory).is_dir():
        print(f"错误：目录不存在 '{directory}'")
        sys.exit(1)

    if command == "prefix":
        prefix = extra_args[0] if extra_args else "new_"
        results = FileOperations.add_prefix(directory, prefix)
        for r in results:
            print(r)

    elif command == "suffix":
        suffix = extra_args[0] if extra_args else "_processed"
        results = FileOperations.add_suffix(directory, suffix)
        for r in results:
            print(r)

    elif command == "timestamp":
        results = FileOperations.add_timestamp(directory)
        for r in results:
            print(r)

    elif command == "organize":
        mode = extra_args[0] if extra_args else "extension"
        if mode == "extension":
            result = FileOperations.organize_by_extension(directory)
        else:
            result = FileOperations.organize_by_date(directory)
        for k, v in sorted(result.items()):
            print(f"{k}: {v} 个文件")

    elif command == "duplicates":
        result = FileOperations.find_duplicates(directory)
        if not result:
            print("未发现重复文件")
        else:
            for size, files in sorted(result.items(), reverse=True):
                print(f"\n大小 {size:,} 字节（{len(files)} 个）：")
                for f in files:
                    print(f"  {f}")


if __name__ == "__main__":
    main()
```

项目通过 `pyproject.toml` 注册了 CLI 入口，安装后可直接使用 `file-processor` 命令：

## 第三部分 - 工具集设计原则

### 命令行工具的好习惯

| 原则 | 说明 | 示例 |
|------|------|------|
| 无参数显示帮助 | 不应直接报错 | `file-processor` → 显示帮助文本 |
| 支持 `--help` | 显式帮助参数 | `file-processor --help` |
| 参数有默认值 | 减少用户必填项 | 前缀默认 `"new_"` |
| 明确错误信息 | 告诉用户哪里错了 | `错误：目录不存在 '/tmp/abc'` |
| 输出有总结 | 告诉用户做了什么 | `完成：共重命名 5 个文件` |

## 常见错误

### 1. sys.argv 索引越界

```python
# ❌ 错误：用户没传参数时 sys.argv[1] 报 IndexError
command = sys.argv[1]

# ✅ 正确：先检查长度
if len(sys.argv) < 2:
    print("请提供命令")
    sys.exit(1)
command = sys.argv[1]
```

### 2. 没有检查目录是否存在

```python
# ❌ 错误：目录不存在时后续操作会报奇怪的错误
directory = sys.argv[2]
results = FileOperations.add_prefix(directory, "new_")

# ✅ 正确：提前验证
if not Path(directory).is_dir():
    print(f"错误：'{directory}' 不是有效目录")
    sys.exit(1)
```

### 3. 忘记处理可选参数

```python
# ❌ 错误：用户不传第三个参数时 IndexError
prefix = sys.argv[3]

# ✅ 正确：extra_args 用列表接收，有默认值
extra_args = sys.argv[3:]
prefix = extra_args[0] if extra_args else "new_"
```
