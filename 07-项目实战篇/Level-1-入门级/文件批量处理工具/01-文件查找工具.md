### 2.1 pathlib 基础

#### 概念说明

`Path` 对象代表一个文件系统路径，比字符串操作更安全、更易读。

```
┌─────────────────────────────────────────────────────────────┐
│                  Path 对象常用属性                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Path("/home/user/docs/report.txt")                         │
│       ├── .name     →  "report.txt"   文件名+扩展名          │
│       ├── .stem     →  "report"       文件名（不含扩展名）    │
│       ├── .suffix   →  ".txt"         扩展名                │
│       ├── .parent   →  Path("/home/user/docs")  父目录       │
│       └── .exists() →  True/False     是否存在              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 示例代码

```python
# path_basics.py
from pathlib import Path

# 创建 Path 对象
p = Path("/tmp/example/report.txt")

print(p.name)    # report.txt
print(p.stem)    # report
print(p.suffix)  # .txt
print(p.parent)  # /tmp/example

# 路径拼接：用 / 运算符代替字符串拼接
docs_dir = Path("/tmp") / "example" / "docs"
print(docs_dir)  # /tmp/example/docs

# 判断类型
print(p.exists())   # 是否存在
print(p.is_file())  # 是否是文件
print(p.is_dir())   # 是否是目录
```

### 2.2 列出目录内容

#### 概念说明

`iterdir()` 遍历目录的直接子项（不递归），返回 `Path` 对象的迭代器。

#### 示例代码

```python
# list_files.py
from pathlib import Path


def list_files(directory: str) -> list[Path]:
    """列出目录下所有文件（不含子目录）"""
    dir_path = Path(directory)
    return [item for item in dir_path.iterdir() if item.is_file()]


def list_dirs(directory: str) -> list[Path]:
    """列出目录下所有子目录"""
    dir_path = Path(directory)
    return [item for item in dir_path.iterdir() if item.is_dir()]


# 使用示例
files = list_files("/tmp")
for f in files:
    print(f.name)
```

### 2.3 按扩展名过滤

#### 概念说明

通过比较 `Path.suffix` 实现扩展名过滤，注意扩展名包含点号（`.txt` 不是 `txt`）。

#### 示例代码

```python
# filter_by_ext.py
from pathlib import Path


def find_by_extension(directory: str, extension: str) -> list[Path]:
    """查找指定扩展名的文件

    Args:
        directory: 搜索目录
        extension: 扩展名，如 ".txt"（含点号）
    """
    dir_path = Path(directory)
    # suffix 返回 ".txt" 形式，统一转小写后比较
    return [
        f for f in dir_path.iterdir()
        if f.is_file() and f.suffix.lower() == extension.lower()
    ]


# 查找所有 .txt 文件
txt_files = find_by_extension("/tmp/docs", ".txt")
for f in txt_files:
    print(f"{f.name}  ({f.stat().st_size} 字节)")
```

**关键代码说明：**

| 代码 | 含义 | 为什么这样写 |
|------|------|-------------|
| `f.suffix.lower()` | 获取扩展名并转小写 | 统一大小写，`.TXT` 和 `.txt` 都能匹配 |
| `f.is_file()` | 只保留文件，排除子目录 | `iterdir()` 会同时返回文件和目录 |
| `f.stat().st_size` | 获取文件大小（字节） | `stat()` 返回文件元数据对象 |

### 2.4 按名称模式匹配

#### 概念说明

`Path.glob(pattern)` 支持通配符匹配，`*` 匹配任意字符，`**` 匹配任意层级目录。

```
┌─────────────────────────────────────────────────────────────┐
│                  glob 通配符规则                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  *         匹配任意字符（不跨目录）                           │
│  ?         匹配单个字符                                      │
│  [abc]     匹配 a、b 或 c                                    │
│  **        匹配任意层级（递归）                               │
│                                                             │
│  示例：                                                      │
│  "*.txt"         当前目录所有 .txt 文件                       │
│  "report_*.csv"  所有 report_ 开头的 csv                     │
│  "**/*.py"       所有子目录中的 .py 文件                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 示例代码

```python
# glob_search.py
from pathlib import Path


def find_by_pattern(directory: str, pattern: str) -> list[Path]:
    """用 glob 模式查找文件"""
    dir_path = Path(directory)
    return [f for f in dir_path.glob(pattern) if f.is_file()]


def find_recursive(directory: str, pattern: str) -> list[Path]:
    """递归查找（深入所有子目录）"""
    dir_path = Path(directory)
    return [f for f in dir_path.rglob(pattern) if f.is_file()]


# 示例
# 查找当前目录所有 report 开头的 csv
reports = find_by_pattern("/data", "report_*.csv")

# 递归查找所有 Python 文件
py_files = find_recursive("/project", "*.py")
for f in py_files:
    print(f.relative_to("/project"))  # 显示相对路径
```

### 2.5 完整实现：FileFinder 类

#### 示例代码

```python
# file_finder.py
from pathlib import Path


class FileFinder:
    """文件查找工具"""

    def __init__(self, directory: str) -> None:
        self.root = Path(directory)
        if not self.root.is_dir():
            raise ValueError(f"目录不存在：{directory}")

    def find(
        self,
        extensions: list[str] | None = None,
        pattern: str = "*",
        recursive: bool = False,
    ) -> list[Path]:
        """查找文件

        Args:
            extensions: 扩展名列表，如 [".txt", ".csv"]，None 表示不过滤
            pattern: glob 模式，默认 "*" 匹配所有文件
            recursive: True 则递归搜索子目录
        """
        search_fn = self.root.rglob if recursive else self.root.glob
        results = [f for f in search_fn(pattern) if f.is_file()]

        if extensions:
            exts = {e.lower() for e in extensions}
            results = [f for f in results if f.suffix.lower() in exts]

        return sorted(results)

    def summary(self, files: list[Path]) -> dict[str, int]:
        """统计各扩展名文件数量"""
        count: dict[str, int] = {}
        for f in files:
            ext = f.suffix.lower() or "(无扩展名)"
            count[ext] = count.get(ext, 0) + 1
        return count


# 使用示例
finder = FileFinder("/project")

# 查找所有 Python 文件
py_files = finder.find(extensions=[".py"], recursive=True)
print(f"找到 {len(py_files)} 个 Python 文件")

# 统计各类型文件数量
all_files = finder.find(recursive=True)
print(finder.summary(all_files))
# {'.py': 12, '.txt': 5, '.json': 3}
```

**关键代码说明：**

| 代码 | 含义 | 为什么这样写 |
|------|------|-------------|
| `self.root.rglob if recursive else self.root.glob` | 根据参数选择递归/非递归搜索 | 避免重复代码，用三元表达式选函数 |
| `{e.lower() for e in extensions}` | 将扩展名列表转为小写集合 | 集合的 `in` 查询是 O(1)，比列表快；统一小写便于比较 |
| `sorted(results)` | 对结果排序 | 保证输出顺序稳定，方便调试和测试 |
| `f.suffix.lower() or "(无扩展名)"` | 无扩展名时用默认分组 | `Path("file").suffix` 返回空字符串，`or` 提供默认值 |

## 第三部分 - os 与 glob 模块对比

### 三种方式对比

| 方式 | 语法 | 优点 | 适用场景 |
|------|------|------|---------|
| `pathlib` | `Path.glob()` / `rglob()` | 面向对象，类型安全，推荐 | 所有新代码 |
| `glob` 模块 | `glob.glob()` | 接受字符串路径，简单直接 | 快速脚本 |
| `os.walk()` | 迭代器 `(root, dirs, files)` | 遍历时可修改 dirs 控制搜索范围 | 需要精细控制递归逻辑 |

```python
# 三种方式实现"递归查找所有 .txt 文件"

# 方式 1：pathlib（推荐）
from pathlib import Path
files = list(Path("/data").rglob("*.txt"))

# 方式 2：glob 模块
import glob
files = glob.glob("/data/**/*.txt", recursive=True)

# 方式 3：os.walk
import os
files = []
for root, dirs, filenames in os.walk("/data"):
    for name in filenames:
        if name.endswith(".txt"):
            files.append(os.path.join(root, name))
```

## 常见错误

### 1. 扩展名忘记加点号

```python
# ❌ 错误
find_by_extension("/tmp", "txt")   # 永远匹配不到

# ✅ 正确
find_by_extension("/tmp", ".txt")
```

### 2. iterdir() 不递归

```python
# ❌ 只能看到一层，子目录里的文件找不到
for f in Path("/data").iterdir():
    print(f)

# ✅ 递归用 rglob
for f in Path("/data").rglob("*"):
    if f.is_file():
        print(f)
```

### 3. glob 结果包含目录

```python
# ❌ glob("*") 同时返回文件和目录
files = list(Path("/data").glob("*"))

# ✅ 过滤掉目录
files = [f for f in Path("/data").glob("*") if f.is_file()]
```
